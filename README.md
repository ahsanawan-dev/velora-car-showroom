## 📌 Project Overview

VELORA Motors is a fictional luxury automotive showroom concept designed to present high-performance cars in a premium digital experience.

The website includes a cinematic landing section, curated car collection, interactive car angle viewer, fullscreen image gallery, smooth scrolling, responsive navigation, and modern UI animations.

This project was created as part of my frontend development journey to improve my skills in layout design, JavaScript interactivity, responsive UI, and GitHub deployment.

---

## ✨ Features

- Premium black and gold luxury design
- Fully responsive layout for desktop, tablet, and mobile
- Interactive car collection section
- Five featured performance cars
- Five image views for each car:
  - Front view
  - Side view
  - Rear view
  - Interior view
  - Wheel/detail view
- Interactive image switching with JavaScript
- Fullscreen gallery modal
- Smooth scrolling navigation
- Sticky header
- Back-to-top button
- Clean section-based layout
- Modern typography and spacing
- GitHub Pages deployment

---

## 🚗 Featured Cars

The project includes a curated selection of luxury and performance vehicles:

1. Lamborghini Revuelto  
2. Ferrari SF90 Stradale  
3. Porsche 911 GT3 RS  
4. McLaren 750S Spider  
5. Mercedes-AMG GT 63  

Each car includes multiple visual angles to create a more immersive showroom experience.
